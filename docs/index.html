❓ 下载与安装常见问题

1. 手机提示「未知来源应用」或风险提示怎么办？
因为本工具为学生个人非商业开源免费项目、未上架商业应用商店，安卓/鸿蒙系统都会弹出常规未知来源提示。确认安装包来自本页并核对上方 SHA-256 后，点击「允许本次安装 / 继续安装」即可。华为鸿蒙 4.x 如开启了「纯净模式」，在提示框选「了解风险并继续安装」即可。
2. 此前装过 v2.7.0 或更早版本，如何升级到新版「海屿空间」？
自 v2.8.0 起已全面启用中性个人开源包名（io.github.rex25415.haiyu.schedule），新版可与旧版并存安装：只需在旧版「设置 → 同班分享码」复制分享码，粘贴进海屿空间 1 秒导入课表（或重新同步一次），再卸载旧图标即可。从 v2.8.0 往后的所有版本（含更名为海屿空间）均保持包名与签名不变，应用内直接无缝覆盖更新、自动保留全部数据！
3. 苹果 iPhone 或鸿蒙 NEXT（5.0+）能用吗？
当前发布包为安卓原生 APK（兼容 Android 8.0–17 与华为鸿蒙 4.x 及以下）；iPhone / 鸿蒙 NEXT 暂无法直接安装 APK，你可以让安卓同学在 App 内使用「导出 .ics 日历」（内置课前提醒闹钟）发给你一键导入苹果日历。
4. 以后会经常弹出更新提醒吗？更新节奏是怎么样的？
不会！刚上线前几版主要在集中补齐核心功能与修复紧急大 Bug，因此连发了较多版本；目前核心已趋于稳定，正式版已转为 每周 1～2 次的稳健迭代节奏（日常不频繁弹窗打扰；仅在教务改版或出现严重故障时随时加急修复）。如果想第一时间试用预览特性，也可以在 App「设置 → 应用更新」打开 Beta 预览通道。
5. 宿舍网打不开网页怎么最快装给室友？
已安装同学可以直接打开 App「设置 → 关于与更新 → 分享给同学」，不仅能面对面扫离线二维码，还可以直接点击「直接传安装包（.apk）给同学」，通过 QQ / 手机互传把安装包发过去，免网页秒装。
